# Camada de software

Esta pasta é reservada à aplicação de software executada fora do Arduino. Ela deve permanecer independente do firmware em `firmware/arduino/`.

Ainda não há uma aplicação implementada nesta camada. Ao adicioná-la, documente aqui sua tecnologia, como executá-la e como ela se comunica com o dispositivo, se essa comunicação fizer parte dos requisitos.
